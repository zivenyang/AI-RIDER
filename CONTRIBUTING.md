# Contributing to AI-RIDER

Thank you for your interest in improving AI-RIDER! This is a **legal document project**, so contributions carry unique responsibilities. Please read this guide carefully before submitting changes.

## ⚠️ Immutability of the Canonical Text

**`AI-RIDER-v1.0.txt` is the sole authoritative text and must not be modified.** Any change to the legal substance constitutes a new version and must go through a formal review process resulting in a new file (e.g., `AI-RIDER-v1.1.txt`).

**No translations or derivative texts are accepted into this repository.** See [Translations & Derivative Works](#translations--derivative-works) below.

## Types of Accepted Contributions

### 1. New Version Proposals (High Impact)
Proposing changes to the legal substance that would result in a new version of the rider.

**Examples:** changing "shall" to "may", adding/removing defined terms, modifying trigger conditions.

**Process:**
- **Always open an Issue first** to discuss the proposed change
- Tag the issue with `legal-substance`
- Wait for maintainer and community review before submitting a PR
- Accepted changes will be published as a **new version** (e.g., `AI-RIDER-v1.1.txt`) — the existing version file is never altered
- Legal professional review is strongly recommended

### 2. Documentation Fixes (Low Impact)
Typos, formatting, README improvements, badge updates.

**Process:**
- Small fixes can be submitted as PRs directly
- Larger documentation restructuring should be discussed in an Issue first

## Translations & Derivative Works

This repository maintains **only the English original** as the single source of truth. We do not accept translation PRs.

If you wish to create a translation or adaptation:

1. **Fork this repository** and create your own branch
2. **Rename your derivative work** — it must NOT be called "AI-RIDER". Use a distinct name (e.g., "AI-RIDER-JP-v1.0", "YourProject-AI-Rider-v1.0")
3. **You bear sole responsibility** for the accuracy and legal enforceability of your derivative work. This project provides no endorsement or guarantee for any translation or adaptation
4. Consider adding a disclaimer in your derivative noting that it is an unofficial translation and that the [original English text](https://github.com/zivenyang/AI-RIDER) is the only authoritative version

**Rationale:** Translations inevitably introduce ambiguity and subtle shifts in legal meaning. Maintaining a single canonical text eliminates disputes over which version controls and preserves the enforceability of the rider.

## Contribution Guidelines

### Public Domain Dedication
By submitting a contribution to this project, you agree that your contribution is dedicated to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). You waive all copyright and related rights to your contribution.

### Code of Conduct
- Be respectful and constructive in all discussions
- Legal and policy topics can be contentious — focus on the substance, not the person
- Assume good faith from all participants

### Pull Request Requirements
1. Clearly describe what your PR changes and why
2. For new version proposals: reference the Issue where the change was discussed
3. PRs that modify `AI-RIDER-v1.0.txt` directly will be rejected
4. PRs that add translation files will be rejected

## Questions?

If you're unsure whether your contribution is in scope, err on the side of opening an Issue first. We'd rather discuss upfront than reject a well-intentioned PR.
